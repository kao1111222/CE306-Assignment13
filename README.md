# ระบบติดตามการยืม-คืนอุปกรณ์ในมหาวิทยาลัย

เว็บแอปจัดการการยืม อนุมัติ ส่งมอบ และรับคืนอุปกรณ์ ธีมหน้าเว็บแบบเกม 8-bit

## โครงสร้างโปรเจกต์

```
university-equipment-system/
├── README.md
├── docs/API.md               รายการ API ทั้งหมด
├── backend/                  Express + Prisma 7 + PostgreSQL (TypeScript)
│   ├── .env.example          ตัวอย่างค่าตั้งค่า (คัดลอกเป็น .env)
│   ├── prisma/               schema.prisma, seed.ts
│   └── src/                  server.ts, lib/, middleware/, routes/
└── frontend/                 หน้าเว็บ (ถูกเสิร์ฟโดย backend)
    ├── index.html
    ├── css/style.css
    └── js/                   core, auth, equipment, my-requests, support,
                              staff, manage, users, profile, app
```

## วิธีรัน

1. ติดตั้ง Node.js (LTS) และ PostgreSQL แล้วเปิด PostgreSQL ให้ทำงาน (พอร์ต 5432)
2. เปิด Terminal ที่โฟลเดอร์ `backend`
3. คัดลอก `.env.example` เป็น `.env` แล้วแก้ `DATABASE_URL` (ใส่รหัสผ่าน PostgreSQL) และ `JWT_SECRET` (ค่าสุ่มยาว ๆ)
4. รันทีละคำสั่ง (รอให้เสร็จก่อนรันคำสั่งถัดไป):

```powershell
npm install
npx prisma generate
npx prisma db push
npm run db:seed
npm run dev
```

5. เปิด http://localhost:3001 (ต้องเปิด Terminal ที่รัน `npm run dev` ค้างไว้)

## บัญชีผู้ใช้

- สมัครสมาชิกเองได้ที่หน้า login (ได้บทบาท "ผู้ยืม")
- ตอนสมัครต้องกรอกรหัสนักศึกษา/บุคลากร ชื่อ เบอร์โทรศัพท์ และอีเมล; เข้าสู่ระบบได้ด้วยอีเมลหรือรหัสนักศึกษา และแก้ไขชื่อ/เบอร์โทรได้ที่หน้าโปรไฟล์
- `npm run db:seed` สร้างบัญชีทดลองผู้ดูแลระบบและเจ้าหน้าที่ (admin@uni.ac.th, staff@uni.ac.th)
  - ถ้าไม่ได้ตั้งรหัสใน `.env` ระบบจะ **สุ่มรหัสผ่านและแสดงใน Terminal ครั้งเดียว** ให้จดไว้
  - หรือกำหนดเองด้วย `SEED_ADMIN_PASSWORD` และ `SEED_STAFF_PASSWORD` ใน `.env` แล้วรัน seed
- แก้ไขข้อมูลผู้ยืมได้ที่แท็บ "ข้อมูลผู้ยืม" และเปลี่ยนรหัสผ่านได้ที่แท็บ "เปลี่ยนรหัสผ่าน"
- หากลืมรหัสผ่าน ให้กด "ลืมรหัสผ่าน?" ที่หน้าเข้าสู่ระบบ ระบบจะส่งลิงก์ตั้งรหัสผ่านใหม่ไปยังอีเมลที่ลงทะเบียน ลิงก์มีอายุ 30 นาทีและใช้ได้ครั้งเดียว
- ผู้ดูแลระบบเปลี่ยนบทบาท/ลบผู้ใช้และดูประวัติการเปลี่ยนแปลงได้ที่แท็บ "ผู้ใช้"

### ตั้งค่าการส่งอีเมล

กำหนดค่าเหล่านี้ใน `backend/.env` เพื่อส่งอีเมลรีเซ็ตรหัสผ่านและแจ้งเตือนคำร้องแจ้งปัญหา (ตัวอย่างใช้ SMTP แบบ STARTTLS):

```env
APP_URL=http://localhost:3001
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM="ระบบยืม-คืนอุปกรณ์ <your-email@gmail.com>"
```

หากใช้ Gmail ให้ใช้ App Password แทนรหัสผ่านบัญชี และอย่าแชร์ไฟล์ `.env` เมื่อต้องเพิ่มตารางใหม่ตาม schema ให้รัน `npx prisma db push` ในโฟลเดอร์ `backend` โดยคำสั่งนี้จะซิงก์ schema กับฐานข้อมูลที่ระบุใน `DATABASE_URL`

ผู้ใช้ที่เข้าสู่ระบบส่งคำร้องได้จากแท็บ "แจ้งปัญหา" และตรวจสอบคำร้องพร้อมสถานะและวันที่ปิดได้ในส่วน "คำร้องของฉัน" คำร้องจะถูกบันทึกในระบบและส่งอีเมลไปยังบัญชีที่มีบทบาทผู้ดูแลระบบ (`ADMIN`) ผู้ดูแลจัดการคำร้องได้จากแท็บ "คำร้องแจ้งปัญหา" โดยเปลี่ยนสถานะเป็น "รอตรวจสอบ", "กำลังดำเนินการ" หรือ "ดำเนินการเสร็จแล้ว"; ระบบจะส่งอีเมลแจ้งผู้ร้องเมื่อสถานะเปลี่ยน หาก SMTP ยังไม่พร้อม คำร้องและสถานะยังทำงานในเว็บไซต์ แต่ระบบจะไม่ส่งอีเมล

## ประวัติและแจ้งเตือน

- ผู้ดูแลระบบดูประวัติการสร้าง/เปลี่ยนสถานะคำขอยืม การเปลี่ยนแปลงอุปกรณ์ และการเปลี่ยนบทบาทหรือลบผู้ใช้ได้ที่แท็บ "ผู้ใช้" > "ดูประวัติการเปลี่ยนแปลง"
- เมื่อมีคำร้องแจ้งปัญหา ระบบส่งอีเมลไปยังผู้ดูแลระบบทุกบัญชีที่มีบทบาท `ADMIN`
- เมื่อ backend ทำงาน ระบบตรวจทุกชั่วโมง ส่งอีเมลก่อนครบกำหนด 24 ชั่วโมง, เมื่อถึงกำหนด, เมื่อเกินกำหนด 1 วัน (เปลี่ยนสถานะเป็น `OVERDUE`), 3 วัน และ 7 วัน
- ต้องตั้งค่า `SMTP_*` ใน `backend/.env` เพื่อส่งอีเมล; หากยังไม่ตั้ง SMTP การเปลี่ยนสถานะ `OVERDUE` และรายการติดตามในเว็บไซต์ยังทำงานอยู่
- สถานะอุปกรณ์จะเปลี่ยนเป็น "กำลังยืม" เมื่อเจ้าหน้าที่กดส่งมอบ และกลับเป็น "ว่าง" เมื่อรับคืน (หรือ "ซ่อมบำรุง" หากชำรุด) โดยหน้ารายการคำนวณสถานะจากคำขอที่กำลังยืมอยู่

## ค่าปรับคืนเกินกำหนด

คืนเกินกำหนดปรับวันละ 20 บาท (ปรับได้ที่ `FINE_PER_DAY` ใน `.env`) นับเป็นวัน ปัดเศษขึ้น ระบบคำนวณตอนเจ้าหน้าที่กดรับคืน และเจ้าหน้าที่กด "รับชำระค่าปรับ" เมื่อผู้ยืมจ่ายแล้ว

## ข้อมูลก่อนยืมและตรวจสภาพอุปกรณ์

- คำขอยืมเก็บข้อมูลผู้ยืมและเวลาที่เลือก พร้อมประวัติวัน/เวลารับและกำหนดคืน
- กำหนดระยะเวลายืม 3–7 วัน และผู้ยืมต้องยืนยันข้อตกลงก่อนส่งคำขอ
- หลังคำขอได้รับอนุมัติ ผู้ยืมกด "ขอรหัสรับอุปกรณ์" ในหน้า "คำขอของฉัน" แล้วแสดงรหัส 6 หลักให้เจ้าหน้าที่หลังตรวจบัตรนักศึกษา รหัสมีอายุ 10 นาที ใช้ได้ครั้งเดียว และเก็บในฐานข้อมูลในรูปแบบแฮช
- เจ้าหน้าที่ต้องกรอกรหัสให้ถูกต้องก่อนส่งมอบ; ล็อกการลองรหัสหลังกรอกผิด 5 ครั้ง โดยผู้ยืมต้องขอรหัสใหม่
- เจ้าหน้าที่ต้องถ่าย/แนบภาพสภาพอุปกรณ์ก่อนส่งมอบและหลังรับคืน รูปภาพ JPG, PNG หรือ WebP จำกัดไม่เกิน 1.5 MB
- ผู้ยืมต้องส่งรูปและหมายเหตุยืนยันการส่งคืนจากหน้า "คำขอของฉัน" ระบบประทับเวลาส่งหลักฐาน; เจ้าหน้าที่ตรวจรูปดังกล่าวก่อนรับคืนจริงและถ่ายรูปตรวจรับอีกครั้ง
- รูปภาพจัดเก็บใน `backend/uploads/request-photos` และเปิดดูได้เฉพาะเจ้าของคำขอหรือเจ้าหน้าที่

## ติดตามอุปกรณ์เกินกำหนดหรือเกิดเหตุ

- ระบบระงับการขอยืมและการอนุมัติใหม่ เมื่อผู้ใช้มีอุปกรณ์เกินกำหนดคืน มีอุปกรณ์สูญหายที่ยังไม่ได้รับคืน หรือมีเคสติดตามที่ยังเปิดอยู่
- เมื่อเกินกำหนด 3 วัน เจ้าหน้าที่ติดต่อผู้ยืมจากหน้าจัดการคำขอและบันทึกผลโทร/อีเมลได้; เมื่อเกินกำหนด 7 วัน ผู้ดูแลบันทึกผลตรวจสอบตามระเบียบมหาวิทยาลัยได้
- เจ้าหน้าที่บันทึกเคสชำรุด สูญหาย หรือติดต่อผู้ยืมไม่ได้ พร้อมหมายเหตุและมูลค่าประเมินได้จากหน้า "จัดการคำขอ"
- เคสสูญหายจะเปลี่ยนคำขอเป็น `LOST` และตัดจำหน่ายอุปกรณ์ เคสชำรุดจะส่งอุปกรณ์เข้าซ่อม
- หากพบอุปกรณ์สูญหายภายหลัง เจ้าหน้าที่กด "บันทึกว่าพบอุปกรณ์แล้ว" แนบภาพและตรวจสภาพ: สภาพปกติจะกลับเป็น "ว่าง" ส่วนชำรุดจะเป็น "ซ่อมบำรุง"; เคสเดิมยังรอผู้ดูแลยืนยันปิด
- ผู้ดูแลระบบต้องบันทึกผลการติดตามและยืนยันปิดเคส เคสที่ยังเปิดอยู่ทำให้ลบบัญชีผู้ยืมไม่ได้

ถ้าอัปเดต schema ให้รัน `npx prisma db push` ในโฟลเดอร์ `backend` และตรวจสอบ `DATABASE_URL` ก่อนทุกครั้ง

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `Cannot find module ... generated/prisma/client.js` | รัน `npx prisma generate` |
| `TableDoesNotExist (P2021)` | ตรวจ `DATABASE_URL` ว่าชี้ฐานข้อมูลที่ถูกต้อง แล้วรัน `npx prisma db push` |
| schema ไม่ตรงกับฐานข้อมูล | รัน `npx prisma db push` ในโฟลเดอร์ `backend` ตรวจสอบฐานข้อมูลก่อนเสมอ |
| `ENOENT package.json` | อยู่ผิดโฟลเดอร์ ให้ `cd backend` ก่อนรัน npm |
| เว็บเข้าไม่ได้ / login ไม่ได้ | ต้องรัน `npm run dev` ค้างไว้ และเปิดผ่าน http://localhost:3001 (ไม่ใช่ไฟล์ html ตรง ๆ หรือ Live Server) |
| `EADDRINUSE` | มี server เปิดซ้อนอยู่ ปิด Terminal เก่าก่อน |
| หน้าตาเว็บไม่อัปเดต | กด Ctrl+F5 |
